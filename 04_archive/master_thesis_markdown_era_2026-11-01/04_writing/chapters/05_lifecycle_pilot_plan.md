## 立项问题

**已提交高斯在场景状态转换下的退出/恢复/补全机制，能否在标准 Bonn
子集上产生可解释的正信号？** 能 → Ch5 立项（可信度驱动生命周期）；
不能 → Ch5 回到未定题，重议候选（备选：动态感知致密化）。

## 现有基础设施（已核实）

- `utils/alpha_lifecycle.py`（411 行，接入 slam_backend `_alpha_lifecycle_step`）
  四臂已按消融隔离实现：
  - `off`（B 臂）：passive deferred，模块 no-op，字节等价基线
  - `observe`（C 臂）：积累 alpha 证据但不行动（安慰剂）
  - `exit`（D 臂）：alpha 更新 + 不透明度重置 + 自由空间 carve

- R9 现行 config 中 `enabled: false`——**从未在标准子集上出过正式
  数字**（pilot 即首次）

## Pilot 设计

| 要素 | 决定 | 理由 |
|---|---|---|
| 序列 | Bonn 标准子集里选 2 条有明确状态转换的（候选：crowd3 有穿越遮挡；balloon2 物体持续移入移出）+ 1 条对照（crowd，已 2.2cm 达标，看是否有增益不劣化） | 状态转换是机制作用面；对照防"只在差序列上看起来有用" |
| 臂 | off / observe / exit / exit_fill × 2 序列 × 2 seeds = 16 run | 最小闭环；observe 安慰剂分离"积累证据"与"采取行动"的效应 |
| 指标 | **第一：绝对 ATE**（≤5cm 红线语境）；第二：残影代理（静态区渲染残差）、背景恢复速度、高斯数、静态序列退化检查 | monogs-ours DISCIPLINE.md rule 7：若成功 ATE 到多少必须能回答 |
| 预注册判据 | exit/exit_fill 在 ≥1 条状态转换序列上 ATE 优于 off 且 observe（安慰剂）不劣化 → 正信号成立 | 安慰剂对照是信号有效性的关键（Phase 1b 的教训：有安慰剂门禁的信号才可信） |
| 成本 | 16 run × ~27min ≈ 7.3 GPU 时（两卡一晚） | |

## 风险与预案

- 若 exit 系列 ATE 持平但渲染/残影改善：定位为"建图质量贡献，
  跟踪无增益"——Ch5 叙事转向地图维护（PSNR/残影主线），ATE 不作为
  其验收标准（需用户确认该定位）
- 若 observe（安慰剂）就劣化：机制本身有害，直接否决选题
- 若全部持平：无信号，Ch5 回未定题（止损，不烧 GPU 调参）
