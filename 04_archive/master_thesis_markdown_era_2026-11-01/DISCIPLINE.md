# DISCIPLINE.md — master_thesis 工作纪律

> 每次进入本项目工作前必须先读本文件（与 monogs-ours/DISCIPLINE.md 同级效力）。

## 提交纪律

1. **最小单元提交**：写完一个文件 / 一个小节 / 一组表格 = 立即 commit + push。
   攒批提交 = 违规
2. 一个逻辑变更一个 commit；commit message 写清楚做了什么
3. 本仓库产出在本仓库提交，不混入 monogs-ours（反之亦然）
4. 每次推进后在 `PROGRESS.md` 工作日志追加一行——这本身也是一个阶段，
   追加完再 commit 一次（或并入本次 commit，二选一，不许漏）

## 写作纪律

1. **单一事实源**：实验数字一律来自 `monogs-ours/results/`（或登记过的
   表格文件），写作时引用不复制；PROGRESS.md 记进度不记数据
2. **参考文献按序号从 1 开始**（导师开题意见 #3）：bib 按正文首次引用
   顺序编号，不按字母序
3. **图要多**（导师意见 #4）：每章至少 2-3 张图，架构图优先；
   图源脚本进 02_analysis/scripts/ 或 03_results/figures/ 附生成代码
4. **学硕三研究内容**（导师意见 #1/#5）：Chapter 3/4/5 各对应一篇
   小论文；系统设计不是重点，三个核心问题才是
5. 草稿用 Markdown（04_writing/chapters/），定稿期转 Word（drafts/
   保留版本历史，命名 thesis_vNN 或 thesis_MMDD）
6. 导师意见全部登记在 06_admin/supervisor/，新增意见先登记再执行

## 与实验仓库的关系

- 实验证据源：`monogs-ours/results/`（只读引用，不复制大文件）
- 已投稿论文权威版：`monogs-ours/papers/MMM2027_RoGS-SLAM_submission.pdf`
- 优先级：实验判决窗口（等待远程批量时除外）> 论文推进 > 其他；
  远程批量运行期间默认切到本项目推进

## 写作四要素规范（用户指示，2026-09-05）

论文 = 内容 + 图 + 表 + 引用，四要素齐了随时可转 Word 定稿：

1. **内容**：小节级 Markdown，放 chapters/；只写内容不排格式
2. **图**：产出即登记 `03_results/figures/REGISTER.md`（文件+章节+数据源+
   生成脚本）；脚本进 02_analysis/scripts/figures/ 可复现；正文相对路径引用
3. **表**：数据表放 03_results/tables/，必须注明 monogs-ours 数据源路径
   （单一事实源原则）；**改表后必跑 verify_tables.py**（58 项自动
   核对，不一致不许提交）
4. **引用**：正文 `[@bibkey]`，条目进 references.bib 且经 arXiv/官方核实
   （未核实的标 [unverified] 并尽快补）；定稿期按 GB/T 7714-2015 排版
5. **格式**：定稿用官方 Word 模板（201504+201609 首页），详见
   04_writing/FORMAT.md；中期检查前评估是否需要提前转 Word

## Codex 使用纪律（2026-09-05 用户二次纠正后补强）

monogs-ours DISCIPLINE.md 既定条款在本仓库同样生效：Codex 只作参考。具体到论文写作：

- Codex 的任何建议（选题、结构、目录布局、写作顺序）：先用本项目
  数据/文献核实其论据 → 自己判断 → 决定采纳/部分采纳/拒绝
- 采纳 Codex 建议的表述纪律：写"首选候选/建议方案"，不写"已定"；
  升格为定论必须来自我方实验/写作实践的直接证据
- 已核实属实的 Codex 论据，在文档中记录核实过程（哪条数据、哪个文件）

## 反 AI 化写作原则（README 既定，2026-09-05 纳入纪律）

README.md 的 15 条反 AI 化原则是**写作的最高约束**，优先级高于
一切行文习惯。每次成稿/扩写/修改后逐段自查；关键五条：

1. 论证驱动结构：每段先回答"在论证链里解决什么问题"
2. 引用必须带立场（支持/反对/补充/修正哪一点），禁止文献走秀
3. 删万能意义句；意义只能从具体发现里长出来
4. 结论写边界（什么条件下成立/不成立），禁止无条件普遍规律
5. 摘要=发现与证据、引言=问题与缺口、结论=答案加边界，三者不重复
