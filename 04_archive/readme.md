# 归档（04_archive）

快照仓。每改到一个里程碑，就把当时的完整状态整份冻在这里，活区
`01_small_papers/MMM2027/` 永远只放最新版。

## 约定

- 目录命名：`<来源>_v<版本>_<日期>`，一次快照一个目录
- 每个快照目录配一份 `MANIFEST.md`，写明这是什么版本、来自哪、与上一版的差别、怎么恢复
- 归档只增不改。已经进来的东西不要再编辑
- 快照冻的是"那一刻的完整可用状态"，不是增量。宁可重复也不要缺件
