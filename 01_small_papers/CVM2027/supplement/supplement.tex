\noindent\emph{Anonymous submission.} This supplement provides the per-system,
per-sequence and per-map detail behind the main paper's summary tables and prose.
Every number is generated by scripts from the same logged artifacts as the main
paper; no new experiments were run. Tables S1--S8 and Fig.~S1 are referenced
in the main text where noted.

\section{Reproduction detail (main paper \S3)}
\paragraph{Protocol.} All eleven reproduced systems were run on the same machine
under one protocol: identical evaluation harness, Horn SE(3) alignment, ATE RMSE in
centimetres, three seeds, all frames. Execution conditions vary across systems:
DynaSLAM and NGD-SLAM run on CPU (ORB-SLAM2 and ORB-SLAM3 bases respectively),
WildGS-SLAM is monocular and receives RGB only, and seed reporting follows each
system's capability. Diverged runs (path length $>5\times$ GT or ATE
$>100$\,cm) are flagged and re-run under the same protocol with recommended
settings; the flag is kept in the table. DynaGSLAM delegates tracking to an external
front-end (DynoSAM poses), so its seeds are deterministic and it is reported without
variance.
\paragraph{Coverage.} Tracking is covered on all eight BONN sequences for every
method. Rendering metrics exist only for methods with a rendering path: DynaSLAM,
NGD-SLAM and ORB-SLAM3 have none, so they are omitted from the rendering tables.
Table~\ref{tabS:ate-base} reports the full reproduction on the
eight BONN sequences, including the two sequences (\emph{mv\_no\_box},
\emph{mv\_no\_box2}) that the main paper's Table~1 excludes because the prior stack
has no run on them; the six-sequence columns are the comparable subset.
Table~\ref{tabS:ate-stack} reports the prior stack on its seven BONN sequences,
including \emph{crowd3}, which no baseline ran. The stack is evaluated on the same
machine and protocol in an independent batch and is reported as background.

\section{Codec detail (main paper \S5)}
\paragraph{Per-sequence working points.} The three fixed bit-width working points on
the 42 frozen maps (seven sequences $\times$ two arms $\times$ three seeds), mean
per sequence. The held-out panel (36 unseen maps, five TUM sequences and one Bonn,
\emph{moving\_obstructing\_box})
reproduces the near-lossless point with per-map ratios spanning 5.72--6.12
(mean 5.96) at $-0.01$\,dB, agreeing with the frozen-map point of the
main paper's Table~4.
\input{tables/supp_codec_seq}
\paragraph{Learned baselines, per-configuration detail.} SOG (Morgenstern et al.,
ECCV 2024) runs its official non-sorted path on the frozen PLYs, both its
unquantised configuration and its quantised configuration; the gap between them is
the evidence that SOG's compression gain is dominated by quantisation, matching the
main paper's finding for the parameter-free codec. The Niedermayr c3dgs row is a
refit (QAT fine-tuning from the frozen map); its reference implementation fixes no
random seed, so per-map values are not reproducible beyond $\approx$0.1\,dB, and the
row is reported without a variance claim.
\input{tables/supp_learned}

\section{Anti-dynamic cost per map (main paper \S6)}
\paragraph{Per-map values.} Each row is one frozen map (sequence $\times$ arm); the
cost of erasing dynamic content, the recoverable fraction under a static insertion,
and the static-side effect. These are the per-map values behind the interval
reported in the main text; the interval is given instead of a mean because the
distribution is sign-mixed on the static side.
\input{tables/supp_dyncost}

\section{Repair, per sequence and seed (main paper \S7)}
\paragraph{Per-cell values.} The locked criteria are J1 $\ge$ 2.5\,dB,
J2 $\le$ 0.70, J3 within $\pm$0.25\,dB; every sequence-and-seed cell passes all
three. Values are samepose medians as in the main paper.
